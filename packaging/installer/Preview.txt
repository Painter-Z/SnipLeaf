SnipLeaf 0.1.4 — 贴图标注锁定开发候选版

轻量截图、标注、置顶贴图与离线 OCR 选字。
Windows 11 x64 为当前验证环境；Windows 10 2004 及以后版本待实机验证。

本安装程序会创建开始菜单入口，可选择桌面快捷方式和开机启动。
主程序可以安装在其他本地磁盘。用于 OCR 的小型身份包单独指定到 Windows 系统盘，不修改其他应用的默认存储位置。
日常使用无需管理员权限、VS Code、C++ 编译器或其他开发工具。

本版本使用专用测试签名，尚非受公众信任的正式发行签名。
为启用 Windows OCR，安装时需要信任 SnipLeaf Preview 专用公共证书。
如当前用户证书信任不足，会出现一次 Windows 管理员确认。
证书只进入“受信任人”库，不进入“受信任的根证书颁发机构”。
卸载会移除本安装添加的证书信任和应用身份；个人设置保留。
此首版试用包暂不覆盖安装；更新或重装时请先卸载旧版，个人设置会保留。

OCR 使用 Windows 已安装的语言组件，截图内容在本机处理。
未安装中文或英文 OCR 语言时，需要在 Windows 语言设置中添加对应的可选功能。
Windows 初次安装语言功能可能需要联网和管理员确认；以后识别可离线使用。
本版不在软件安装过程中下载 Windows 语言组件，缺少语言不会导致软件安装回滚。
安装完成页会提示缺少的语言。可自愿打开独立 OCR 准备窗口，或稍后在托盘“设置”中点击“配置 OCR 语言…”。
已有的识别语言可以先用；没有任何 OCR 语言时，截图、标注、贴图可用，文字识别需补齐语言后使用。
独立准备窗口显示组件名称及 Windows 进度，先检查同语言基础组件，再安装 OCR；不安装语音、手写等功能。
组件下载慢时请查看窗口进度，不必重新安装 SnipLeaf。补齐后请退出再启动软件；只有 Windows 要求时才需要重启电脑。
独立准备日志保存在 %LOCALAPPDATA%\SnipLeaf\Diagnostics\每次操作的目录\，包括 ocr-prerequisites.json 和 dism.log。
软件安装日志保存在 %TEMP%\SnipLeaf-install-last.log。日志可能包含本机路径，反馈时请私下提供。

默认快捷键：F1 截图，F3 贴图，Shift+F3 全部显隐。
图片文字拖选后 Ctrl+C；空白拖动移动；Tab 展开贴图工具栏；Esc 取消／关闭。
空白单击立即取消 OCR 选字。新贴图默认锁定标注，仍可移动整张图片、缩放和 OCR 选字复制。
Tab 或右键显示标注工具栏后解锁编辑；再次隐藏时完成当前编辑并锁定，保留已有撤销历史。
截图或工具栏显示的贴图中，文字输入框透明、随内容伸缩；输入时拖动细边框移动，完成后直接拖动文字，双击修改。
解锁时选中标注后 Delete／Del 或 Backspace 删除，Ctrl+Z 撤销。输入文字时按键用于正常编辑字符。

仅供受邀人员试用。请勿把本测试证书作为通用证书安装，勿将本版标记为已完成正式发布验收。
