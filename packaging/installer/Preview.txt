SnipLeaf 0.1.11 — 双文本框与分段阅读候选版

轻量截图、标注、置顶贴图与离线 OCR 选字。
新增可选联网英译中：选中文字后点击“译”，无选区时翻译全文；贴图隐藏工具栏时可右键翻译。
翻译面板恢复上下两个文本框：上方显示可编辑英文，下方显示完整中文，便于大块阅读、选择和复制。
中文不同段落之间空一行，同段内容随窗口宽度自动折行，列表各项独立分段。
原文保留 OCR 换行，可直接修改错字或用空行调整段落，Ctrl+Enter 重译；复制译文保留段落空行。
支持取消请求，不改写原图片或解锁标注；本版移除对照表和行号定位。
从托盘“翻译设置”配置你自己的百度通用文本翻译 APPID 与密钥，并勾选启用联网翻译。
使用“开发者信息”中的密钥，不能用新控制台的 API Key 替代。额度和费用以你的百度账户规则为准。
密钥使用 Windows DPAPI 加密，保存在当前用户的 SnapLite\translation.dat；安装包不包含共享密钥。
只有主动使用联网翻译时才发送待译文字到百度官方 HTTPS 接口，不上传图片，不记录原文或密钥。
正常卸载保留用户加密配置；如需删除，请先在翻译设置中点击“清除凭据”。
技术门槛为 Windows 10 2004（19041）及以后的 x64 Windows，以及 Windows 11 x64。
开发机验证环境为 Windows 11；用户反馈旧包在 Windows 10 以管理员身份运行可安装，新版的普通权限安装仍待该机复测。

本安装程序会创建开始菜单入口，可选择桌面快捷方式和开机启动。
主程序可以安装在其他本地磁盘。用于 OCR 的小型身份包单独指定到 Windows 系统盘，不修改其他应用的默认存储位置。
日常使用无需管理员权限、VS Code、C++ 编译器或其他开发工具。

本版本使用专用测试签名，尚非受公众信任的正式发行签名。
为启用 Windows OCR，可在安装时主动勾选信任 SnipLeaf Preview 专用公共证书。
如当前用户证书信任不足，会出现一次 Windows 管理员确认。
证书只进入“受信任人”库，不进入“受信任的根证书颁发机构”。
卸载会移除本安装添加的证书信任和应用身份；个人设置保留。
此首版试用包暂不覆盖安装；更新或重装时请先卸载旧版，个人设置会保留。

身份包是软件的本地包名、版本和发布者标识，不是微软或 GitHub 账号。每台电脑为自己的 Windows 用户注册本安装包附带的身份；不会共享截图或识别内容，也不需要开发者账号。
新版会先校验身份包副本，再从标准本地缓存交给 Windows 部署服务读取；不修改原安装目录权限。
OCR 身份准备失败或未同意信任时，基础程序安装仍保留，完成页明确提示 OCR 尚未就绪。
需要时从托盘“设置”选择“修复 OCR 身份…”，完成后退出并重新启动 SnipLeaf。
程序启动检查失败时会单独警告，不表示截图或 OCR 已可使用。安装载荷校验失败仍会停止安装并回滚。
本改进不能解除智能应用控制或企业应用控制拦截；请按系统安全策略使用，正式分发仍需要可信签名或合适渠道。

OCR 使用 Windows 已安装的语言组件，截图内容在本机处理。
未安装中文或英文 OCR 语言时，需要在 Windows 语言设置中添加对应的可选功能。
Windows 初次安装语言功能可能需要联网和管理员确认；以后识别可离线使用。
本版不在软件安装过程中下载 Windows 语言组件，缺少语言不会导致软件安装回滚。
安装完成后首次启动会在后台检查 OCR 身份以及中英文识别引擎；已经可用的双语言不会重复下载。
身份可用而缺少语言时，显示 OCR 准备面板，8 秒后请求 Windows 管理员确认并仅补齐缺少的组件。
可选择“稍后 / 关闭”，以后通过托盘“OCR 准备…”或“设置”中的“配置 OCR 语言…”继续，不会每次启动重复弹出。
已关闭自动 OCR 的用户不会自动开始语言准备。缺身份或检查失败时，面板说明原因，不直接下载语言。
OCR 身份已就绪时已有的识别语言可以先用；没有任何 OCR 语言时，截图、标注、贴图可用，文字识别需补齐语言后使用。
面板分别显示中英文 OCR 是否可用，以及中文基础、中文 OCR、英文基础、英文 OCR 四项实际状态。
先检查所有目标组件，再按基础语言、OCR 的顺序补齐；不安装语音、手写等功能。
进度条表示已核实安装的组件数量，不是下载百分比。另显示当前组件和观察用时，Windows 暂无更新时明确说明仍在处理。
关闭面板或退出 SnipLeaf 不终止系统语言准备，再次启动可重新连接仍在运行的本次进程，避免重复下载。
组件下载慢或失败时不回滚软件。结束后重新验证 OCR 引擎并刷新现有贴图；当前进程未取得新引擎时会提示重开软件。
只有 Windows 要求时才需要保存工作并重启电脑，软件不会自动重启。
独立准备日志保存在 %LOCALAPPDATA%\SnipLeaf\Diagnostics\每次操作的目录\，包括 ocr-prerequisites.json 和 dism.log。
软件安装日志保存在 %TEMP%\SnipLeaf-install-last.log。日志可能包含本机路径，反馈时请私下提供。

默认快捷键：F1 截图，F3 贴图，Shift+F3 全部显隐。
截图后按 F3、Ctrl+T 或点击贴图，保留截图在屏幕上的位置和原尺寸，不自动居中或缩小。
本次运行中复制的截图，在剪贴板没有更换时，再按 F3 也恢复原位置；从其他软件复制的图片仍使用常规贴图位置。
框选使用深色中心、白色描边十字，在灰色遮罩和不同明暗背景下保持可见；鼠标拖动时持续使用同一光标。
图片文字拖选后 Ctrl+C；空白拖动移动；Tab 展开贴图工具栏；Esc 取消／关闭。
空白单击立即取消 OCR 选字。新贴图默认锁定标注，仍可移动整张图片、缩放和 OCR 选字复制。
Tab 或右键显示标注工具栏后解锁编辑；再次隐藏时完成当前编辑并锁定，保留已有撤销历史。
截图或工具栏显示的贴图中，文字输入框透明、随内容伸缩；输入时拖动细边框移动，完成后直接拖动文字，双击修改。
解锁时选中标注后 Delete／Del 或 Backspace 删除，Ctrl+Z 撤销。输入文字时按键用于正常编辑字符。

仅供受邀人员试用。请勿把本测试证书作为通用证书安装，勿将本版标记为已完成正式发布验收。

图像复制与缩小阅读：
右键“复制 PNG 文件（原尺寸）”或 Ctrl+Shift+F 复制整张图片为 PNG 文件；在支持文件粘贴的应用中粘贴。目标应用可能仍将其按图片发送，可先保存 PNG，再通过文件附件入口发送。
文件保存在 %LOCALAPPDATA%\SnapLite\Share，每次成功复制新文件时仅清理该目录下超过七天的自有分享 PNG，当前文件保留。普通图片复制不写入此分享缓存。
原 Ctrl+C、Ctrl+Shift+C 和 Ctrl+0 保留。右键新增 100% 原始大小和 200% 放大阅读；缩小贴图时后台生成面积采样预览，原图、OCR、保存与复制不随显示倍率改变。
