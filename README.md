# 拾贴 SnipLeaf

轻量 Windows 截图、标注、置顶贴图与离线 OCR 工具。

本次归档 **0.1.0 x64 Preview** 原始安装包。F1 截图，F3 贴到屏幕，在图片上拖选文字后 Ctrl+C 复制。

软件支持矩形、椭圆、箭头、直线、文字、马赛克和记号笔；标注可再次选择和调整，支持撤销与重做。OCR 使用 Windows 系统语言组件，在本机离线识别。

打开 GitHub Releases，在本版本 Assets 中下载 `SnipLeaf-0.1.0-x64-Preview-Setup.exe`。[完整发布说明与校验值](docs/releases/v0.1.0.md)。

当前为专用测试签名的预览版，安装需要明确同意证书信任，可能请求管理员确认。缺少 OCR 语言组件时需要 Windows 联网补齐；本机 Windows 11 x64 已验证，干净机器和 Windows 10 尚待独立验收。
