# SnipLeaf 快速入门

以下操作以 0.1.1 Preview 为准。[安装说明](INSTALLATION.md)介绍首次安装和升级。

## 截图和贴图

按 **F1** 拖动框选。拖动边框或角点调整范围，拖动没有文字的空白处移动选区。按 **F3** 将当前截图贴在屏幕上；平时按 F3 会贴出剪贴板图片。

贴图默认直接支持选字。空白处拖动移动，滚轮缩放，**Ctrl+0** 恢复 100%；按住 **Space** 拖动可以从文字等任意位置移动。

**Shift+F3** 隐藏／显示全部贴图。**Tab** 展开／收起贴图工具栏。**Esc** 先取消当前编辑或选择，无活动操作时关闭贴图；需要的内容请在关闭前保存，本版不保留关闭后的贴图恢复历史。

## 在图片上复制文字

后台识别结束后，在文字或文字边缘按下鼠标并拖动，出现高亮后按 **Ctrl+C**。截图和贴图都支持此操作，中文通常按识别器返回的字／词框选择，英文通常按词选择。

- **O** 切换到选字模式，**Ctrl+A** 选择全部识别文字。
- 单击空白处立即取消高亮。
- 有文字选区时 **Ctrl+C** 复制文字，无文字选区时复制图片。
- **Ctrl+Shift+C** 强制复制图片。
- 漏字时右击图片，选择“增强识别文字”重试；增强处理不会改变显示或保存的图片。

移动、缩放或显隐贴图会复用已有识别结果。修改标注后会重新识别当前可见图片；与马赛克相交的识别词不提供复制。

## 标注

| 快捷键 | 工具 |
| --- | --- |
| R / E | 矩形／椭圆 |
| A / L | 箭头／直线 |
| T | 文字 |
| M / P | 马赛克／记号笔 |
| V / O | 选择标注／选字 |

点击颜色按钮选择颜色；线条工具点击粗细按钮调整线宽。**Shift+拖动**使直线、箭头和记号笔吸附角度，使矩形或椭圆绘制为正方形或圆形。记号笔默认是一条直线。

文字工具在图片上单击后输入，**Enter** 完成，**Shift+Enter** 换行，**Esc** 取消输入。文字输入框透明，实时显示所选颜色，尺寸随内容变化。输入时拖动细边框移动；完成后在文字工具中直接拖动文字标注，双击重新编辑。字号按钮可输入 **6–288 pt**，支持一位小数。

马赛克默认 **8 px** 方格。粗细位置的数字可切换 6／8／12／16 px，长条区域保持方格比例。

按 **V** 点击标注边界选中，拖动边框移动，拖动控制点改变尺寸；直线和箭头可拖动两端。**Delete／Del 或 Backspace** 删除选中标注，**Ctrl+Z / Ctrl+Y** 撤销／重做。输入文字时删除键正常编辑字符。

## 保存和复制图片

截图状态按 **Enter** 或双击空白处，复制图片并结束截图。**Ctrl+S** 保存 PNG。

贴图放大时，应用添加的文字和形状会按显示尺寸重绘；截图原有文字仍受源像素限制。右键“缩放显示”可以选择清晰缩放或像素显示。保存为 PNG 后重新打开，原标注已成为图片像素。

## 托盘与热键

右击托盘图标可截图、贴图、设置快捷键和 OCR 语言、退出程序。默认热键与其他截图软件冲突时，可以退出占用软件，等待自动重试，或修改 SnipLeaf 的快捷键。
