# 贴图自动保存与恢复

0.1.12 起，未主动关闭的贴图会自动保存。从托盘退出 SnipLeaf，重新启动后恢复图片、独立标注、文字、位置、缩放、平移和清晰／像素显示模式。

## 操作规则

- 停止移动、标注或显隐约 600 ms 后在后台保存；正常退出前等待最后一次保存完成，并确认正在输入的文字。
- 隐藏的贴图恢复后仍隐藏，按 **Shift+F3** 显示。
- 恢复时工具栏收起、标注锁定；按 **Tab** 可继续编辑各个标注对象。
- **Ctrl+W、双击空白或 Esc 最终关闭**表示不再保留该贴图。只是暂时收起，请用 **Shift+F3**。
- 原显示器仍可用时保留位置，包括副屏负坐标。原显示器移除、贴图不可拖到时，会移回最近的现有屏幕。混合 DPI 的显示器更换仍需实际检查。
- 尚未贴出的截图窗口、撤销／重做历史、OCR 选区和翻译面板不跨重启保存。OCR 按现有设置重新识别。

0.1.11 及更早版本没有恢复记录。首次升级到新版前，仍需手动保存旧版中的重要贴图；升级无法找回旧版退出时丢弃的图片。

## 数据保存在何处

`%LOCALAPPDATA%\SnapLite\Pins\session.dat`，设置目录沿用旧名以保持兼容。整个文件使用 Windows 当前账户的 DPAPI 加密，仅在本机保存，不上传图片。缓存包含原始底图与可编辑标注，因此也包含马赛克遮盖前的底图信息，请按原图的敏感程度对待它。

正常卸载保留缓存，同一 Windows 账户重装新版后可以恢复。若需清理，关闭全部贴图并正常退出，会保存空会话；也可以退出程序后删除 `Pins` 文件夹。不要在程序仍运行时删除，否则自动保存会重新创建。

它是会话恢复，不是备份。更换 Windows 账户、重装系统或缓存损坏可能导致无法解密；重要图片请另存 PNG。断电／强制结束进程只能恢复最后成功写入的状态。保存失败会提示；正常退出保存失败时保留当前窗口，方便检查磁盘空间后重试。

缓存无法读取时保留为 `session-unreadable-*.dat`，不会自动回退旧会话而复活已关闭贴图。当前缓存格式最多保存 128 张图、总计 134,217,728 个底图像素、10,000 个标注和 512 MiB 序列化数据，超过时会提示保存失败。

## 验证

新增 28 项检查，覆盖像素及全部标注属性往返、多图与负坐标、平移缩放、显隐、独立编辑、真正的自动保存计时器、退出／关机文字提交、后台保存与错误重试、原子替换及损坏数据处理。其中包含两个独立进程的退出／重启检查。测试使用合成图片与专用缓存，不接触个人贴图或翻译凭据。
