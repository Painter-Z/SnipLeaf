# SnipLeaf 0.1.12 · 贴图自动保存与恢复

## 新增

- 退出 SnipLeaf 后重新启动，自动恢复未主动关闭的贴图，保留图片、独立标注、文字、原位置、缩放和平移。
- 隐藏状态及清晰／像素显示模式一起恢复；恢复时标注保持锁定，按 Tab 展开工具栏后可继续修改。
- 自动保存由后台线程完成。正常退出会确认正在输入的文字并等待最后一次保存，避免退出后空列表覆盖原会话。
- 主动关闭贴图会同步移除恢复记录；原显示器断开时，将不可见贴图移回现有屏幕。
- 恢复数据使用当前 Windows 账户加密，在本机保存，不上传图片。写入失败保留上一有效记录并提示。

## 下载

- 安装软件：下载 `SnipLeaf-0.1.12-x64-Preview-Setup.exe`，约 3.12 MiB。**请使用管理员身份安装**。
- 完整源码：下载 `SnipLeaf-0.1.12-source.zip`，或查看 `v0.1.12`／`source-v0.1.12` 标签。本版自动生成的 Source code 附件也包含同版代码。
- 安装包与源码各自附 SHA256SUMS 文件。旧版本的安装包、提交、标签和源码附件继续保留。

## 更新前须知

当前试用包需先退出并卸载旧版，再安装新版。**0.1.11 及更早版本没有贴图恢复功能，退出旧版前请先手动保存重要图片**，新版无法找回此前丢弃的贴图。个人设置、翻译配置和新版产生的贴图缓存正常卸载后保留。

恢复缓存位于 `%LOCALAPPDATA%\SnapLite\Pins`，包含原始底图及可编辑标注；重要图片仍需单独另存 PNG。重装 Windows、更换账户或缓存损坏可能导致无法恢复。Ctrl+W／Esc 最终关闭表示不再保留；暂时收起用 Shift+F3。

此版本沿用 Preview 测试签名，没有解决智能应用控制或组织应用策略的信任限制。管理员身份不保证绕过这些限制。Windows 10、多屏混合缩放、HDR 和不同安全策略仍需实机验收。
