# SnipLeaf 0.1.7 Preview

截图转贴图保留原位置与尺寸，继续提供高对比框选十字和首次 OCR 准备。

- 按 F3、Ctrl+T 或点击工具栏“贴图”，图片内容保持在截图原来的位置，以原尺寸显示；一像素边框向外扩展，不再自动居中、缩小或挤入工作区。
- 使用最终选区的物理屏幕坐标，支持移动／调整后的截图、负坐标及跨屏大截图。
- 同次运行中先复制截图再按 F3，剪贴板未变更时恢复原位置；复制已缩放的贴图时保留当时的显示比例。
- 保留 0.1.6 的高对比十字及独立 OCR 准备面板：首次启动检查中英文引擎，缺语言且身份可用时引导准备，显示四项组件真实状态及等待时间，下载失败不回滚软件。
