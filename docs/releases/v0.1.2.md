## 安装与限制

当前为自签名试用包，安装需明确同意信任 SnipLeaf Preview 专用公共证书，可能请求 Windows 管理员确认。智能应用控制或安全软件可能拒绝安装或运行；开源不改变签名信誉。更新前请保存贴图、退出并卸载旧版，个人设置及 Windows OCR 语言保留。语言组件缺失时需额外联网准备。

历史包保留构建时的行为及限制；当前源码公开不会修复其安装流程。
