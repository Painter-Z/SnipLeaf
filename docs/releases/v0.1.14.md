# SnipLeaf 0.1.14 · 增强离线 OCR 与自由画笔

Windows x64 Preview，安装包原始字节归档，未重新编译或重签。2026-11-16 发布。

## 更新内容

内置 PP-OCRv6 Small 中英文增强 OCR，无需另装 .NET、Windows 语言包或注册 MSIX 身份；保留 Windows OCR 兼容引擎。新增 B 自由画笔，支持曲线、圆点、闭合及交叉笔迹、移动缩放和贴图恢复，P 仍为直线记号笔。

## 下载与使用

下载本页 Assets 中的 **SnipLeaf-0.1.14-x64-Preview-Setup.exe**，无需下载 Source code。安装包约 29.68 MiB。

**请使用管理员身份安装。** 默认增强 OCR 可直接使用，向导的证书项只用于 Windows 兼容引擎。本历史安装包仍要求先退出并卸载旧版；需要直接覆盖升级请使用 0.1.15。

安装包仍为自签名预览版；Windows 智能应用控制、企业策略或安全软件仍可能阻止 EXE、DLL 或脚本，管理员权限不保证解除拦截。软件不会自动更改系统安全策略。

## 验证与隐私

最终签名程序通过 245 项功能、中英文 OCR 与 9 张合成质量样本。9 图共 17,943 字符，81 个编辑错误；样本结果不代表任意截图准确率。 本机测试不代替所有 Windows 10／11、不同安全策略和干净机器验收。新版安装包未在本次发布过程中替换本机日常安装版。

OCR 在本机离线完成；联网翻译仅在主动使用时发送待译文字到百度，不上传图片。每位用户配置自己的翻译账户，安装包没有共享密钥或个人测试截图。
