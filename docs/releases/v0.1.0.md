# SnipLeaf 0.1.0 Preview

历史首版。原安装包构建于 2026-10-09，推荐新用户试用 0.1.1。

## 功能

- F1 截图，七类可编辑标注，F3 置顶贴图。
- 中文和英文离线 OCR，在截图和贴图中拖选文字复制。
- 自定义 pt 字号、矢量标注缩放、方格马赛克和一像素渐变贴图边框。

## 安装前提

当前为专用测试签名版本，尚无公众信任的生产签名。安装需明确同意信任 SnipLeaf Preview 专用公共证书，可能需要 Windows 管理员确认。OCR 缺少系统语言组件时，还可能需要联网安装和重启；组件齐全后识别在本机离线运行。

本机 Windows 11 x64 已验证，干净机器和 Windows 10 尚待独立验收。更新或重装需先退出并卸载已有版本，个人设置和 Windows OCR 语言保留。
