# SnipLeaf 0.1.1 Preview

原安装包构建于 2026-10-10。推荐当前试用此版本。

## 本次更新

- OCR 拖选后，单击空白立即取消高亮。
- 文字输入框透明并随内容伸缩；长文在图片范围内换行。
- 输入时拖动细边框移动，完成后直接拖动文字标注，双击重新编辑。
- Delete／Del 和 Backspace 均可删除选中标注，并支持撤销与重做。
- 修复非整数缩放下的无修改文字历史记录，以及拖动途中删除后标注恢复的问题。

## 安装与验证范围

当前为专用测试签名版本，尚无公众信任的生产签名。安装需明确同意信任 SnipLeaf Preview 专用公共证书，可能需要 Windows 管理员确认；缺 OCR 语言时，补齐组件可能需要联网和重启。

本机 Windows 11 x64 已通过 115 项功能检查、中英文 OCR 样例及 8 张合成 OCR 质量样本。干净机器、Windows 10、多屏混合 DPI 和真实输入法候选窗口仍需进一步验收。重要识别文字请核对。
