# 联网英译中

截图或贴图中拖选英文，点击工具栏“译”；没有文字选区时翻译识别到的全文。工具栏隐藏时也可通过右键“英译中：所选文字／全文（联网）”使用。

## 配置账户

1. 在 [百度翻译开放平台](https://fanyi-api.baidu.com/) 开通通用文本翻译，按平台要求完成认证。
2. 在开发者信息页取得成对的 **APPID 和密钥**。此版本使用这组凭据，新版控制台的 API Key 不能直接填入这里的密钥框。
3. 在 SnipLeaf 托盘“翻译设置…”中填写，勾选“启用联网翻译”并保存，再回到面板翻译。

联网翻译默认关闭，安装包没有共享密钥。每位用户使用自己的百度账户，额度、限流和费用以平台当时的规则为准；截图、标注、贴图和离线 OCR 不需要翻译账户。

## 阅读和复制

上方文本框显示可编辑的英文原文，下方显示完整中文译文。原文保留 OCR 换行，译文按窗口宽度折行，段落之间空一行，便于连续阅读。

可以在英文框修正错字、添加空行调整段落，再点击翻译或按 Ctrl+Enter。普通段落内的截图折行会合并后翻译，明显的段落间距、空行与列表用于划分段落；没有明显分隔时可能需要手动补空行。

中文框支持跨段拖选、Ctrl+A 和 Ctrl+C。“复制译文”复制已完成的中文并保留段落空行；窗口宽度造成的视觉折行不会成为多余换行。出现“部分完成”时，请核对提示后再复制。

翻译期间可取消或按 Esc；空闲时 Esc 关闭面板。修改原文、编辑或关闭原图片会取消关联的旧请求，避免过期结果覆盖当前内容。

## 数据与保存

OCR 使用 Windows 本机引擎。只有主动翻译且已启用功能时，软件才通过 HTTPS 向百度官方通用文本翻译接口发送待译文字，不上传图片。软件不把待译正文、密钥或服务端原始响应写入诊断日志。

凭据使用 Windows DPAPI 加密，保存在当前用户的 `%LOCALAPPDATA%\SnapLite\translation.dat`，沿用旧目录名以兼容设置。安装包和公开仓库不包含个人凭据。正常卸载保留此配置；可以在“翻译设置…”中“清除凭据”，关闭联网功能并删除本机配置。不要向别人发送这个文件。

已发送的文字无法通过后续修改图片或马赛克撤回。涉及隐私的内容请先核对待译原文。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 认证失败／签名错误 | 检查 APPID 与密钥是否成对，是否误填 API Key 或多余空格 |
| 未开通服务或额度不足 | 检查自己百度账户的服务状态、额度和余额 |
| 超时或请求失败 | 检查网络与 Windows 系统代理，减少所选文字后手动重试 |
| 中文段落不符合预期 | 在英文框用空行调整段落，再按 Ctrl+Enter 重译 |
| 只完成部分内容 | 核对状态提示，重新选择未完成部分翻译；软件不自动重试付费请求 |

当前公开应用源码仍为 0.1.4，尚不包含联网翻译；此文说明 0.1.11 安装版的使用方式。
