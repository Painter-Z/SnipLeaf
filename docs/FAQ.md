# 常见问题

## 可以免费使用和修改吗？

SnipLeaf 自身内容按 MIT 许可证提供，允许使用、修改、再分发及商用，并要求保留版权和许可声明。详见仓库 `LICENSE` 与 `NOTICE.md`。Windows 和其他开发工具仍适用其自身许可。

## 开源后为什么安装仍有安全提示？

源码许可和 Windows 代码签名是两个独立事项。当前 0.1.0–0.1.4 安装包使用专用自签名试用证书，没有公众信任的正式签名。智能应用控制可能阻止程序，安全软件可能提示 PowerShell 部署和证书信任；公开源码不改变已有 EXE 的信誉。安装限制见 [安装说明](INSTALLATION.md)。

## 为什么贴图中的文字标注拖不动或删不掉？

0.1.4 在工具栏隐藏时锁定标注，避免误操作。按 Tab 或右键显示标注工具栏后即可编辑；整张贴图仍可移动和缩放，OCR 选字也可继续使用。

## 为什么 Ctrl+C 复制出了图片？

Ctrl+C 在有文字选区时复制文字，没有选区时复制图片。先等待 OCR 完成，按 O 回到选字模式，再拖选文字。Ctrl+Shift+C 始终复制图片。

## 没有中文或英文识别语言怎么办？

右键托盘 → 设置 → 配置 OCR 语言…。已有语言可以先使用，独立准备窗口会显示补齐进度。下载失败不会回滚软件；补齐后退出再启动，只有 Windows 要求时才需要重启。

## 图片中的文字为什么会识别错？

识别效果受字形、字号、背景、模糊程度和语言组件影响。可右键使用“增强识别文字”，重要内容请人工核对。样本测试结果不能保证所有截图正确。

## 为什么保存后不能再移动单独的箭头或文字？

当前 PNG 输出合并了标注与原图。重新打开时只保留像素，还没有可恢复独立标注的项目文件格式。

## F1 或 F3 没有反应？

可能被其他截图软件占用。托盘设置可调整截图和贴图热键；退出占用软件后会自动重试注册，也可以使用托盘菜单截图。

## 为什么老版本的 Source code 压缩包没有应用代码？

没有保存可核实的 0.1.0–0.1.3 应用源码快照，旧标签仅用于归档发布文档和原始安装包信息。完整应用源码从 v0.1.4 开始；没有把当前源码冒充为旧版本源码。

## 可以贡献代码吗？

欢迎。请阅读 [参与开发](../CONTRIBUTING.md) 与 [构建说明](BUILD.md)，提供改动目的和验证结果。
