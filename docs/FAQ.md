# 常见问题

## 可以免费使用和修改吗？

SnipLeaf 自身内容按 MIT 许可证提供，允许使用、修改、再分发及商用，并要求保留版权和许可声明。详见仓库 `LICENSE` 与 `NOTICE.md`。Windows 和其他开发工具仍适用其自身许可。

## 开源后为什么安装仍有安全提示？

源码许可和 Windows 代码签名是两个独立事项。当前发布的安装包均使用专用自签名试用证书，没有公众信任的正式签名。智能应用控制可能阻止程序，安全软件可能提示 PowerShell 部署和证书信任；公开源码不改变已有 EXE 的信誉。管理员身份也不保证绕过应用控制，安装限制见 [安装说明](INSTALLATION.md)。

## 为什么贴图中的文字标注拖不动或删不掉？

0.1.4 在工具栏隐藏时锁定标注，避免误操作。按 Tab 或右键显示标注工具栏后即可编辑；整张贴图仍可移动和缩放，OCR 选字也可继续使用。

## 为什么 Ctrl+C 复制出了图片？

Ctrl+C 在有文字选区时复制文字，没有选区时复制图片。先等待 OCR 完成，按 O 回到选字模式，再拖选文字。Ctrl+Shift+C 始终复制图片。

## 没有中文或英文识别语言怎么办？

0.1.7 首次启动自动检查中英文 OCR；缺语言且身份可用时显示准备面板，8 秒后请求管理员确认，可选择稍后。也可右键托盘 → OCR 准备…，或设置 → 配置 OCR 语言…。面板显示四项组件实际状态和等待时间，已有语言可以先使用，下载失败不会回滚软件。缺身份时先从设置修复身份；补齐后按提示重开软件，只有 Windows 要求时才需要重启。

## 为什么贴图不再自动居中？

0.1.7 将截图保留在原来的屏幕位置，并按原尺寸贴出；F3、Ctrl+T 与工具栏按钮行为一致。同次运行中复制的截图，剪贴板未更换时再按 F3 也会恢复位置。需要移动时拖动空白处，或按住 Space 拖动。

## 图片中的文字为什么会识别错？

识别效果受字形、字号、背景、模糊程度和语言组件影响。可右键使用“增强识别文字”，重要内容请人工核对。样本测试结果不能保证所有截图正确。

## 为什么发送到手机后文字还是模糊？

原图的像素、聊天应用压缩、聊天缩略图和手机显示缩放都可能影响观感。0.1.11 保持复制图片的原始尺寸，并提供 Ctrl+Shift+F／右键“复制 PNG 文件（原尺寸）”。如果聊天应用仍将文件按图片发送，可先保存 PNG，再从文件附件入口发送，接收后查看实际文件。放大不能恢复截图时没有的笔画。

PNG 文件复制使用 `%LOCALAPPDATA%\SnapLite\Share` 缓存；每次成功复制新文件时，仅清理超过七天的自有分享文件，保留当前文件。普通图片复制不生成这些文件。

## 英译中需要联网吗？有共享账户吗？

翻译需要联网，在“翻译设置…”中自行填写百度通用文本翻译 APPID／密钥并启用；安装包没有共享账户。主动翻译时仅向百度发送待译文字，不上传图片，OCR 仍在本机运行。英文与中文使用上下两个文本框，中文段落之间空一行，可整段选择复制。配置和隐私说明见 [翻译说明](TRANSLATION.md)。

## 为什么保存后不能再移动单独的箭头或文字？

当前 PNG 输出合并了标注与原图。重新打开时只保留像素，还没有可恢复独立标注的项目文件格式。

## F1 或 F3 没有反应？

可能被其他截图软件占用。托盘设置可调整截图和贴图热键；退出占用软件后会自动重试注册，也可以使用托盘菜单截图。

## 为什么老版本的 Source code 压缩包没有应用代码？

没有保存可核实的 0.1.0–0.1.3 应用源码快照，旧标签仅用于归档发布文档和原始安装包信息。完整应用源码从 v0.1.4 开始；没有把当前源码冒充为旧版本源码。

## 可以贡献代码吗？

当前 `main` 和 `source-v0.1.11` 已公开完整 0.1.11 应用源码。旧版源码保存在 `v0.1.4`，更新前的仓库另存为 `source-v0.1.4`；提交与已有标签不改写。注意 `v0.1.11` 是之前仅更新安装包和文档时创建的标签，它的自动 Source code 附件仍含 0.1.4 应用源码。下载新版请选 `SnipLeaf-0.1.11-source.zip` 或 `source-v0.1.11`，见 [源码历史](SOURCE_HISTORY.md)。

欢迎。请阅读 [参与开发](../CONTRIBUTING.md) 与 [构建说明](BUILD.md)，提供改动目的和验证结果。
