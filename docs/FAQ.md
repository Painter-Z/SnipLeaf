# 常见问题

## 为什么安装时需要证书和管理员确认？

当前是使用专用自签名证书的 Preview。Windows OCR 的应用身份包需要建立对应签名信任。安装向导会明确征求同意，必要时请求管理员确认；软件日常使用不需要管理员权限。正式生产签名尚未办理。

## OCR 是否上传截图？

OCR 使用 Windows 自带识别器，截图和识别正文在本机处理，组件就绪后支持离线使用。首次补齐 Windows OCR 语言功能可能需要 Windows 联网下载。

## 为什么有时复制的是图片？

有高亮文字选区时 Ctrl+C 复制文字；没有文字选区时复制图片。先等待后台识别完成，再按 O 并拖选文字。Ctrl+Shift+C 始终复制图片。

## 贴图后怎样复制文字？

直接在贴图文字上拖选，再按 Ctrl+C。无须展开工具栏。按住 Space 拖动可从文字位置移动贴图；单击空白清除文字选区。

## 大图或密集文字有漏字怎么办？

右击选择“增强识别文字”重试，也可在设置中选择已安装的语言。极小字、低清晰度图片和相似字仍可能误识别，重要内容请核对。

## 为什么放大图片不能无限清晰？

文字标注和形状可以按缩放重绘，原截图包含的字已经是像素。高质量缩放能够改善显示，无法恢复截图中不存在的细节。

## 为什么更新提示先卸载？

0.1.0／0.1.1 尚不支持覆盖更新。保存需要保留的贴图，退出并卸载旧版，再安装新版；个人设置和系统 OCR 语言组件保留。

## 下载的 Source code 压缩包为何没有 EXE？

本仓库只公开使用文档和版本资料。GitHub 自动生成的压缩包不是应用源码，也不是安装包。请打开 Releases，在对应版本的 Assets 中下载 EXE。

## 软件是否开源？

目前不公开源码，也未采用开源许可证。可以下载和试用官方预览安装包，其他授权见 [使用与许可说明](../NOTICE.md)。

## 怎样反馈问题？

在仓库 Issues 中选择问题反馈，提供 SnipLeaf 版本、Windows 版本、显示器缩放比例、复现步骤和预期结果。截图与日志请先去除个人信息。
