# 安装、更新与卸载

## 下载

在 [0.1.15 Releases](https://github.com/Painter-Z/SnipLeaf/releases/tag/v0.1.15) 的 Assets 中选择 `SnipLeaf-0.1.15-x64-Preview-Setup.exe`。安装包约 29.67 MiB，仅需一个 EXE，包含中英文增强 OCR 模型和所需运行时。每个版本提供 SHA256 校验文件和公开发布清单，可用 PowerShell 的 `Get-FileHash -Algorithm SHA256` 核对安装包。

历史安装包保持原始字节，供追溯使用。0.1.13–0.1.15 本次仅更新安装包和文档，公开应用源码仍为 0.1.12；最新标签的自动 Source code 附件不是对应新版源码，见 [源码历史](SOURCE_HISTORY.md)。

## 安装

1. 右键 EXE，选择“以管理员身份运行”，阅读试用说明，确认文件来源。
2. 默认增强 OCR 不需要勾选证书项，可直接下一步。只有准备使用 Windows OCR 兼容引擎时，才需要明确同意信任 **SnipLeaf Preview** 公共证书并注册身份。证书只加入“受信任人”，不加入根证书库；安装包不含私钥。
3. 选择安装位置、桌面快捷方式及是否开机启动。默认位置为 `%LOCALAPPDATA%\Programs\SnipLeaf`，开机启动默认关闭。主程序可选择其他本地磁盘，OCR 身份包部署到系统 AppX 卷，不修改其他应用的默认存储位置。
4. 安装完成后默认启动 SnipLeaf，也可从桌面或开始菜单启动。日常运行使用普通用户权限，无需编译器、Windows SDK、CMake、另装 .NET 或独立 VC 运行库。

当前 EXE／OCR DLL 仍为试用签名，没有公众信任的生产签名；智能应用控制、企业策略或安全软件可能阻止程序或安装脚本。管理员身份不保证绕过应用控制。公开源码不会改变签名信誉。

## OCR 语言

**0.1.14 起默认内置 PP-OCRv6 Small 中英文离线增强引擎**，无需下载语言包或注册身份。初次识别在后台加载模型；密集和超长图片可能需数秒至十余秒。设置中可改用 Windows OCR 兼容引擎，增强执行失败时默认模式会尝试回退。下面的语言准备仅供 Windows 兼容引擎或旧安装包使用。

OCR 使用 Windows 已安装的语言组件。已有中文或英文组件时可直接识别，语言齐全后识别可离线使用。没有任何语言时，截图、标注和贴图仍可用。

安装过程不下载语言组件。首次启动在后台实际检查中文、英文 OCR 引擎；已齐全时不下载。缺语言且身份可用时显示独立准备面板，8 秒后请求 Windows 管理员确认，也可立即准备或选择稍后。关闭自动 OCR 的用户不自动开始准备；缺身份或检查失败时先说明原因。

面板显示中文基础、中文 OCR、英文基础、英文 OCR 四项状态、当前步骤和等待时间。进度条表示已核实安装的组件数量，不是下载百分比。只安装缺少的组件，不安装语音和手写。Windows 长时间没有新进度时保持等待说明，允许后台继续；下载失败不回滚软件。

关闭面板或退出 SnipLeaf 不结束系统准备，重新启动可连接本次仍在运行的进程。选择稍后后不反复弹出；通过托盘“OCR 准备…”或“设置”→“配置 OCR 语言…”继续。补齐后重新验证引擎，当前进程未取得新引擎时按提示退出并重开，只有 Windows 要求时才需重启电脑。

历史 0.1.0–0.1.2 的语言准备流程可能导致长时间等待或安装回滚，建议使用 0.1.15。

## 更新与卸载

**运行 0.1.15 安装包可以直接覆盖升级，无需手动卸载。**沿用原目录和一个卸载记录；安装器自动核对运行中旧版的路径，请求保存贴图并正常退出，再检查文件占用并备份程序和安装记录。支持同版本重装，阻止降级及升级时改变目录。默认不重新注册 Windows 身份或添加新证书信任。

新版初始化、OCR 或版本核验失败时尝试恢复旧程序、安装状态、公共证书、卸载器和注册项；旧版此前正在运行时尝试重新启动。恢复受阻时保留备份并提示，路径为 `%LOCALAPPDATA%\SnipLeaf\UpgradeBackups\每次操作目录`。突然断电或强制终止安装器不属于自动恢复的已验证范围。

设置、翻译配置和加密贴图缓存保留。0.1.12 起未主动关闭的贴图会自动保存，下次启动恢复；0.1.11 及更早版本退出前仍需手动保存重要图片，升级无法找回旧版已丢弃的贴图。历史 0.1.14 及更早安装包本身仍要求先卸载，升级能力由新安装包提供。详见 [贴图恢复](PIN_SESSION.md)。

卸载移除程序、快捷方式、应用身份及本次安装新增的专用证书信任，可能再次请求管理员确认。个人设置 `%LOCALAPPDATA%\SnapLite\settings.ini` 与 Windows OCR 语言组件保留；设置目录沿用项目旧名以保持兼容。不要安装后手动移动程序目录，OCR 身份与安装位置关联。

联网翻译账户需在托盘“翻译设置…”中自行配置。凭据由 Windows 加密保存在 `%LOCALAPPDATA%\SnapLite\translation.dat`，正常卸载会保留；不希望保留时可在卸载前“清除凭据”。不要向别人发送此配置文件。详见 [翻译说明](TRANSLATION.md)。

## 已验证与待验证

0.1.15 最终签名程序在本机通过 245 项功能检查和中英文 OCR；9 项真实安装器隔离测试覆盖运行中升级、重装、文件占用、失败恢复及多次升级后卸载，另通过 16 项部署和 31 项前提／语言流程检查。使用独立 AppId、路径和合成数据，不等同于新的干净机器完整安装。本次发布不替换日常安装版。

安装器最低门槛为 Windows 10 2004。用户反馈旧包在 Windows 10 以管理员身份运行可安装，在 Windows 11 关闭智能应用控制后可安装；这是旧包的实测，不保证新版在所有策略下可安装。新版目标 Windows 10 完整安装、无开发环境的干净机器、缺语言实际下载及不同安全策略仍待实机验证。当前不提供 ARM64 或 32 位包。

## 问题反馈

- 软件安装日志：`%TEMP%\SnipLeaf-install-last.log`。
- 安装自检：安装目录中的 `installation-check.json`。
- 独立语言准备：`%LOCALAPPDATA%\SnipLeaf\Diagnostics\每次操作目录\` 下的进度报告和 DISM 日志。

提供软件版本、Windows 版本、错误码、触发步骤和相关日志。日志可能含用户名、证书信息和安装路径，请去除个人信息后再发到公开 Issues。
