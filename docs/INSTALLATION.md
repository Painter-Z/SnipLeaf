# 安装、更新与卸载

## 下载

在 [0.1.7 Releases](https://github.com/Painter-Z/SnipLeaf/releases/tag/v0.1.7) 的 Assets 中选择 `SnipLeaf-0.1.7-x64-Preview-Setup.exe`。安装包约 3.01 MiB，仅需一个 EXE。每个版本提供 `SHA256SUMS.txt` 和发布清单，可用 PowerShell 的 `Get-FileHash -Algorithm SHA256` 核对安装包。

历史 0.1.0–0.1.6 安装包保持原始字节，供追溯使用。当前公开应用源码为 0.1.4；本次 0.1.5–0.1.7 仅更新安装包和文档，标签中的源码仍是 0.1.4。

## 安装

1. 右键 EXE，选择“以管理员身份运行”，阅读试用说明，确认文件来源。
2. 启用 OCR 应用身份需要明确同意信任 **SnipLeaf Preview** 专用公共证书。它是自签名代码签名叶证书，加入“受信任人”，不加入根证书库；安装包不含私钥。Windows 可能请求管理员确认。不授权或身份准备失败时保留基础安装，可稍后从设置“修复 OCR 身份…”继续；OCR 需要可用身份。
3. 选择安装位置、桌面快捷方式及是否开机启动。默认位置为 `%LOCALAPPDATA%\Programs\SnipLeaf`，开机启动默认关闭。主程序可选择其他本地磁盘，OCR 身份包部署到系统 AppX 卷，不修改其他应用的默认存储位置。
4. 安装完成后默认启动 SnipLeaf，也可从桌面或开始菜单启动。日常运行使用普通用户权限，无需编译器、Windows SDK、CMake 或独立安装 VC 运行库。

当前 EXE 仍为试用签名。已在外部 Windows 11 上确认智能应用控制拒绝加载旧版主程序；0.1.7 同样没有公众信任的生产签名，可能遇到同类限制。管理员身份不保证绕过应用控制。安全软件也可能对 PowerShell 部署和证书信任发出提示。公开源码不会改变这些安装行为。

## OCR 语言

OCR 使用 Windows 已安装的语言组件。已有中文或英文组件时可直接识别，语言齐全后识别可离线使用。没有任何语言时，截图、标注和贴图仍可用。

0.1.7 安装过程不下载语言组件。首次启动在后台实际检查中文、英文 OCR 引擎；已齐全时不下载。缺语言且身份可用时显示独立准备面板，8 秒后请求 Windows 管理员确认，也可立即准备或选择稍后。关闭自动 OCR 的用户不自动开始准备；缺身份或检查失败时先说明原因。

面板显示中文基础、中文 OCR、英文基础、英文 OCR 四项状态、当前步骤和等待时间。进度条表示已核实安装的组件数量，不是下载百分比。只安装缺少的组件，不安装语音和手写。Windows 长时间没有新进度时保持等待说明，允许后台继续；下载失败不回滚软件。

关闭面板或退出 SnipLeaf 不结束系统准备，重新启动可连接本次仍在运行的进程。选择稍后后不反复弹出；通过托盘“OCR 准备…”或“设置”→“配置 OCR 语言…”继续。补齐后重新验证引擎，当前进程未取得新引擎时按提示退出并重开，只有 Windows 要求时才需重启电脑。

历史 0.1.0–0.1.2 的语言准备流程可能导致长时间等待或安装回滚，建议使用 0.1.7。

## 更新与卸载

当前试用安装包不支持覆盖安装。保存所需贴图，从托盘退出，再在 Windows“已安装的应用”中卸载旧版，之后安装新版。程序退出时，未保存的贴图会关闭。

卸载移除程序、快捷方式、应用身份及本次安装新增的专用证书信任，可能再次请求管理员确认。个人设置 `%LOCALAPPDATA%\SnapLite\settings.ini` 与 Windows OCR 语言组件保留；设置目录沿用项目旧名以保持兼容。不要安装后手动移动程序目录，OCR 身份与安装位置关联。

## 已验证与待验证

0.1.7 实际打包程序已在本机 Windows 11 x64 通过 146 项功能检查、真实中英文 OCR 和 8 张合成质量样本；43 项安装／语言脚本检查通过。私有未注册身份的基础安装副本完成真实安装／卸载及 141 项基础检查，原日常安装、设置和信任保留。该副本修改测试产品名和身份元数据，不等于新版正式身份安装已完成实机验收。

安装器最低门槛为 Windows 10 2004。用户反馈旧包在 Windows 10 以管理员身份运行可安装，在 Windows 11 关闭智能应用控制后可安装；这是旧包的实测，不保证新版在所有策略下可安装。新版目标 Windows 10 完整安装、无开发环境的干净机器、缺语言实际下载及不同安全策略仍待实机验证。当前不提供 ARM64 或 32 位包。

## 问题反馈

- 软件安装日志：`%TEMP%\SnipLeaf-install-last.log`。
- 安装自检：安装目录中的 `installation-check.json`。
- 独立语言准备：`%LOCALAPPDATA%\SnipLeaf\Diagnostics\每次操作目录\` 下的进度报告和 DISM 日志。

提供软件版本、Windows 版本、错误码、触发步骤和相关日志。日志可能含用户名、证书信息和安装路径，请去除个人信息后再发到公开 Issues。
