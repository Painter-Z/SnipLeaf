# 安装、更新与卸载

## 下载

在仓库 Releases 的 Assets 中选择 `SnipLeaf-0.1.4-x64-Preview-Setup.exe`。0.1.4 约 2.97 MiB，仅需一个 EXE。每个版本提供 `SHA256SUMS.txt` 和发布清单，可用 PowerShell 的 `Get-FileHash -Algorithm SHA256` 核对安装包。

历史 0.1.0–0.1.3 保持原始字节，供追溯使用。它们没有可核实的应用源码快照；完整源码从 0.1.4 开始提供。

## 安装

1. 双击 EXE，阅读试用说明，确认文件来源。
2. 安装需要明确同意信任 **SnipLeaf Preview** 专用公共证书。它是自签名代码签名叶证书，加入“受信任人”，不加入根证书库；安装包不含私钥。Windows 可能请求管理员确认。
3. 选择安装位置、桌面快捷方式及是否开机启动。默认位置为 `%LOCALAPPDATA%\Programs\SnipLeaf`，开机启动默认关闭。主程序可选择其他本地磁盘，OCR 身份包部署到系统 AppX 卷，不修改其他应用的默认存储位置。
4. 安装完成后从桌面或开始菜单启动 SnipLeaf。日常运行使用普通用户权限，无需编译器、Windows SDK、CMake 或独立安装 VC 运行库。

当前 EXE 仍为试用签名。已在外部 Windows 11 上确认智能应用控制拒绝加载旧版主程序；0.1.4 没有获得公众信任的生产签名，可能遇到同类限制。安全软件也可能对 PowerShell 部署和证书信任发出提示。公开源码不会改变这些安装行为。

## OCR 语言

OCR 使用 Windows 已安装的语言组件。已有中文或英文组件时可直接识别，语言齐全后识别可离线使用。没有任何语言时，截图、标注和贴图仍可用。

0.1.4 安装过程不下载语言组件。可在安装完成页自愿打开准备窗口，或稍后右键托盘 → 设置 → 配置 OCR 语言…。独立窗口显示组件与进度，首次准备可能需要联网和管理员确认；下载失败不回滚软件。补齐后退出再启动 SnipLeaf，只有 Windows 要求时才需重启电脑。

历史 0.1.0–0.1.2 的语言准备流程可能导致长时间等待或安装回滚，建议使用 0.1.4。

## 更新与卸载

当前试用安装包不支持覆盖安装。保存所需贴图，从托盘退出，再在 Windows“已安装的应用”中卸载旧版，之后安装新版。程序退出时，未保存的贴图会关闭。

卸载移除程序、快捷方式、应用身份及本次安装新增的专用证书信任，可能再次请求管理员确认。个人设置 `%LOCALAPPDATA%\SnapLite\settings.ini` 与 Windows OCR 语言组件保留；设置目录沿用项目旧名以保持兼容。不要安装后手动移动程序目录，OCR 身份与安装位置关联。

## 已验证与待验证

0.1.4 已在本机 Windows 11 x64 完成旧版卸载、新版安装、启动、设置保留和真实中英文 OCR。实际安装程序通过 127 项功能检查及 8 张合成质量样本；30 项安装／语言准备替身检查通过。

安装器最低门槛为 Windows 10 2004。Windows 10、无开发环境的干净机器、缺语言的实际下载及不同安全策略仍待独立实机验证。当前不提供 ARM64 或 32 位包。

## 问题反馈

- 软件安装日志：`%TEMP%\SnipLeaf-install-last.log`。
- 安装自检：安装目录中的 `installation-check.json`。
- 独立语言准备：`%LOCALAPPDATA%\SnipLeaf\Diagnostics\每次操作目录\` 下的进度报告和 DISM 日志。

提供软件版本、Windows 版本、错误码、触发步骤和相关日志。日志可能含用户名、证书信息和安装路径，请去除个人信息后再发到公开 Issues。
